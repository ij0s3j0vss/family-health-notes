# 【技术】不开刀，不流血，手术还可以玩手机~~海扶刀吸引香港病人来就医

> 更新时间：2026-09-16 (UTC+8)

----------
"做这个手术不辛苦，还可以跟医生护士随时互动，几好！”来自香港的苏女士因子宫内多发肌瘤，日前在我院海扶中心治疗，手术时她还玩起了手机，听起了歌。

高强度聚焦超声技术

（海扶刀）

苏女士边手术边和护士聊天、听歌

苏女士今年48岁，9年前发现子宫内有多发肌瘤，近几年肌瘤不断增大，并出现经量增多伴有贫血症状，在香港医院就诊时，医生建议，彻底解决子宫肌瘤的办法就是开腹切除子宫。

想到要切除子宫，还要开腹手术在肚子上留道疤，苏女士内心非常抗拒。

“难道没有既消除肌瘤，又保留子宫的法子了吗？”不甘心的苏女士通过网络搜索解决子宫肌瘤的办法，了解到内地有一种高强度聚焦超声技术（海扶刀HIFU）可消融子宫肌瘤，不用开刀，还能保留子宫，不影响女性内分泌功能。

她搜索到佛山有医院也在开展这项技术，正好苏女士有个亲戚在佛山，了解得知我院海扶中心在华南地区开展最早、例数做的最多，于是决定来佛山就医。

“查体时，腹部检查就可以摸到患者的子宫已经增大到像孕5个月的孕妇。完善检查后核磁共振上可以看到，患者子宫内的肌瘤大大小小有几十个，有的在肌壁间，有的在浆膜下，最大的达61mm×60mm×64mm，由于子宫比较大，已不能使用腹腔镜等微创的方法，所以香港的医生建议开腹切除子宫。”我院海扶治疗中心主任陈向东表示。

那么，海扶刀治疗多发性子宫肌瘤，一次性能消融多少个呢？这是苏女士最关心的问题。陈向东主任解释说，海扶刀治疗不受肌瘤大小和数目的限制，只要机载超声定位能够看得见的、能够建立安全超声治疗通道的，通常都能够进行消融。一般来讲，几个、十几个、甚至几十个子宫肌瘤，海扶刀都可进行一次性消融治疗，只有少数患者肌瘤特别大、个数特别多，或者位置不好的情况，可能需要分两次进行消融治疗。

4月2日，苏女士在镇静镇痛下接受了超声消融治疗。“做的时候不辛苦，偶尔腰骶部有点疼痛，跟医生交流了一下，及时调整治疗剂量，就不痛了。”

术后第一天苏女士就可以正常下床活动，她表示基本没感觉到痛，跟没事人一样。术后第一天行核磁共振检查，结果显示多数病灶呈大部分缺血坏死改变，病情稳定，苏女士开心地出院了。

术后第二天，苏女士专程找到陈向东主任，并与她合影留念。

**什么是海扶刀（****HIFU****）**

HIFU 是利用超声波的可聚焦性和能量可透人性，在超声或MRI引导下，从体外将低能量的超声波聚集于体内病灶，引起瞬态高温效应后，使靶区内组织温度在0.5～1.0秒骤升至65～100℃，使受损组织出现凝固性坏死继而逐渐被机体溶解吸收或纤维化。适用于要求保留子宫者，尤其适合于不能耐受或不愿意手术治疗者。

 

**海扶刀有什么优点？**

HIFU治疗子宫肌瘤的优点有：

1.为非侵入操作，具有无创性，无辐射，皮肤无任何损伤；

2.无需麻醉，操作前可给予镇静或镇痛药，患者在清醒状态。下即可完成治疗，减少麻醉引起的风险；

（3）能保留子宫及生育能力、不影响女性正常内分泌功能；

（4）患者不良反应较小，多发子宫肌瘤及再发子宫肌瘤可重复治疗；

（5）治疗安全性高，不良反应少，痛苦小，术后恢复快，不影响患者工作生活；

（6）治疗时无需进行输血治疗、营养治疗等，减少了患者治疗费用。

 HIFU属于真正意义上的无创治疗。治疗后主要的并发症状有腹部、腰骶部隐痛、腿部发麻、疲乏感、腹胀、阴道出血或血性分泌物（常见于黏膜下肌瘤）等，多与治疗超声的热效应和机械效应导致的无菌性炎症反应有关，通常在数周内恢复。

**海扶刀做完可以怀孕吗？**

海扶刀做完子宫肌瘤以后三个月就可以怀孕了。

**海扶刀痛吗？**

海扶刀是不需要麻醉的，说明疼痛级别不是很高，甚至没有感觉。像子宫肌瘤，好多患者手术当中是没有不舒服的。有些患者会有轻微的下腹不适或者疼痛。都可以忍受。
