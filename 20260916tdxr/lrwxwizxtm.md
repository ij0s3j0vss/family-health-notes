# 肝病专家送“干货”！ 我院肝胆病诊疗中心开展“世界肝炎日”义诊活动

> 更新时间：2026-09-16 (UTC+8)

7月28日是第十个世界肝炎日，今年活动的主题是“没有肝炎的未来”。南阳市第一人民医院肝胆病诊疗中心组织专家在9号楼前开展义诊活动，号召全社会共同关注肝炎防治工作。

义诊现场，各位专家耐心地为前来咨询的市民解惑，讲解各类肝炎的特点、临床表现、传播途径及预防措施等知识，为各类肝炎患者的抗病毒治疗提供科学依据。

医院肝胆病诊疗中心内科病区主任、主任医师史代萌介绍，今年我国确定的肝炎日主题是“积极预防、主动检测、规范治疗，全面遏制肝炎危害。” 旨在号召公众积极主动接种肝炎疫苗，主动进行体检了解肝脏健康状况，慢性病毒性肝炎患者接受规范的抗病毒治疗，全面遏制病毒性肝炎对人类健康的威胁。

我们南阳市第一人民医院肝胆病诊疗中心特聘请中华医学会肝病学分会第七届主任委员、佑安肝病感染病专科医疗联盟执行理事长、首都医科大学肝病转化医学研究所所长段钟平教授担任中心首席专家，并建立“段钟平教授专家工作站”，指导中心建设及学科发展，定期会诊疑难重症肝病患者。另外还聘请6名国内外知名肝胆病专家定期到本中心坐诊、查房、手术和指导科研教学。

义诊活动中免费为群众抽取血样，进行乙肝、丙肝筛查；对于已确诊的乙肝患者，为其提供进口试剂检测乙肝表面抗原全定量，进一步确认治愈可能性；对于抗体阳性的丙肝患者，筛查高灵敏HCV RNA病毒载量和HCV基因分型检测。

本次活动通过多种形式宣传肝病科普知识，提高大家关注肝病的意识，推动公众维护肝脏健康。请您关注“肝脏”健康，我院肝胆病诊疗中心将与您一路“肝”胆相照，共同前行！

肝胆病诊疗中心设内科、外科两个病区，分别位于9号楼10、9楼。

**肝胆病诊疗中心内科病区**

**开展的主要业务技术:**

1. 中晚期肝癌综合治疗（内科、介入、放疗、靶向、免疫、康复）。特别是对部分不能手术的中期肝癌，经综合治疗后转化为可手术治疗；对手术后的肝癌病人采取以免疫重建为主的综合治疗后，显著降低复发风险。

2. 超声/CT引导下肝囊肿、肝血管瘤、肝脏结节治疗,门静脉癌栓超声介入治疗

3. 肝硬化内科、内镜、营养、TIPS治疗及中西医结合治疗。特别是对肝硬化严重并发症如顽固性腹水、食管胃底静脉曲张出血、自发性腹膜炎、肝昏迷及肝肾综合征等，有独特疗效。

4. 遗传代谢性肝病和自身免疫性肝病诊疗

5. 肝衰竭及人工肝治疗。对病毒学肝炎、肝硬化、药物性肝损伤、酒精性肝病及自身免疫性肝病引起的急性、慢加急性肝衰竭，通过早期预警指标的监测，及早进行综合干预，使病人在肝衰竭前期得到及时有效的控制，救治成功率明显提高。

**肝胆病诊疗中心外科病区**

**开展的主要业务技术****:**

1.肝脏肿瘤:3D技术指导下的精准肝切除术、腹腔镜规则肝叶切除术为我科特色技术。肝门部胆管癌的个体化治疗。腹腔镜肝囊肿开窗引流术。

2.肝囊肿、肝血管瘤在超声/CT引导下射频消融治疗。

3.腔镜胆囊切除术，腹腔镜保胆取石术、腹腔镜联合胆道镜、十二指肠镜、液电碎石仪微创治疗肝内外胆管结石。

4.胰腺肿瘤：腹腔镜/开腹胰十二指肠切除术，腹腔镜保脾的胰体尾肿瘤切除术，腹腔镜脾脏部分/全切除术。

5.荧光腹腔镜精准引导下的复杂肝胆胰脾疾病的腹腔镜微创治疗为我科特色技术。

6.腹腔镜技术：常规实施普外科常见疾病的腹腔镜微创治疗。胃肠道肿瘤的腹腔镜微创治疗。疝与腹壁疝的无张力修补术及腹腔镜微创治疗（TEP、TAPP)

7.自体骨髓干细胞联合脾切除+贲周血管离断术治疗失代偿期肝硬化、门脉高压、脾亢、上消化道出血。
